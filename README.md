# runner-probe

This is a throwaway diagnostic repository. It was created to test whether the `salam-kairos`
GitHub org can get GitHub-hosted Actions runners assigned on a **public** repository, which has
no billing gate, as part of investigating why Actions runs in `salam-kairos/contracts` (a private
repo) stay queued forever with no runner ever assigned. This repo exists only for that experiment
and will be deleted once the test is complete.
